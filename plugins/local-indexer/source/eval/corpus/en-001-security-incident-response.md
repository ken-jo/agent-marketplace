# Security Incident Response Procedure

관련 / Keywords: 보안 사고 대응

This procedure defines how the company responds to information security incidents.

- Any employee who detects an incident must report it to the security operations team immediately.
- The security team assesses the scope and contains the threat to prevent it from spreading.
- Compromised accounts and systems are isolated without delay.
- After containment, the team performs a root cause analysis and defines preventive measures.
- Major incidents are escalated to management and the relevant authorities.

The incident response plan is validated through regular tabletop drills.

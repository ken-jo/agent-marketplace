# 병가 사용 규정

관련 / Keywords: 병가 질병 입원 진단서 휴가

본 문서는 병가 사용 에 관한 사내 기준을 정의한다.

- 질병이나 부상으로 근무가 어려운 경우 연간 60일 한도 내에서 병가를 신청한다.
- 3일을 초과하는 병가는 의사의 진단서를 첨부해야 한다.
- 업무상 재해로 인한 병가는 별도의 산재 처리 절차를 따른다.
- 병가 기간 중 급여는 취업규칙에 정한 비율로 지급한다.
- 장기 병가가 필요한 경우 휴직 전환 여부를 인사팀과 협의한다.

병가 신청은 사유 발생 즉시 부서장에게 보고하고 시스템에 기록한다.

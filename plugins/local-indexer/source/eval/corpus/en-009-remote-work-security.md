# Remote Work Security Guideline

관련 / Keywords: remote work security VPN device endpoint

본 문서는 Remote Work Security Guideline 에 관한 사내 기준을 정의한다.

- Remote access to internal systems requires the corporate VPN.
- Devices used for remote work must run approved endpoint protection.
- Public Wi-Fi use for sensitive work is discouraged.
- Screens must be locked when the device is unattended.
- Lost or stolen devices must be reported to security immediately.

Remote work security complements the password and VPN access policies.
